The Saade Planner — Quick Guide

1. Choose Year and Starting Month. For the school year, choose August.

2. Add events directly under each month using Date, Category, Icon, and Event. For a period, type 1-6 in the Date field.

3. The calendar colors each day automatically: one event fills the whole day, two or three events create color bands, and four or more add a small +.

4. Your planner saves automatically in this browser. Use Export Backup before clearing browser data or moving to another device.

5. Use Print Mode and then Print / Save PDF for a clean A3-style printout.
